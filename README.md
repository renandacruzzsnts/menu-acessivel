# 🍴 Cardápio Oceânico Acessível

Este é um projeto de **Cardápio Digital** focado em acessibilidade para pessoas com deficiência visual e analfabetismo funcional.

## 🚀 Funcionalidades
- **Narração ao Toque:** Utiliza a *Web Speech API* para ler o nome, descrição e preço dos pratos ao passar o dedo ou mouse.
- **Seletor de Voz:** O usuário pode escolher a voz do narrador que mais lhe agrada entre as disponíveis no sistema.
- **Design Minimalista:** Interface limpa com foco em alto contraste e facilidade de navegação.

## 🛠️ Tecnologias
- HTML5 / CSS3 (Flexbox)
- JavaScript Vanilla (SpeechSynthesis)
- Hospedagem: Vercel
